# 提出用サマリー

**AWS ECS Fargate × Terraform 構築・運用演習**  
**2026年10月23日（JST）／mika-it-labs**

## 目的と実施内容

コンテナ基盤をコードで構築し、起動・監視・停止・削除までの運用サイクルとIAM権限を学びました。

Terraform AWS provider 6系を用いて、東京リージョンの既存default VPCを参照し、クラスター、タスク定義、IAM実行ロール、管理ポリシー関連付け、ロググループ、SGの6リソースを管理しました。Apache httpd:2.4をCPU 256／512 MiBで起動し、CLIの状態確認とCloudWatch Logsの起動ログを組み合わせて稼働を確認しました。

## 対応力と学び

削除時にはIAMの参照権限不足でロールが残りました。エラーのAPI名と対象を読み取り、残存リソースを確認し、再実行で削除完了と空のstateを確認しました。作成だけでなく削除にも参照権限が必要なこと、途中失敗時に完了とみなさないことを学びました。

## 成果物と評価範囲

構成図、元のTerraformコード、操作手順、匿名化した検証結果、障害対応、学び、削除手順を収録しています。根拠は添付操作ログと実施者報告です。公開準備時のAWS再実行は行っていません。

外部受信は許可せず、public IPは外向き通信に使用しました。HTTP疎通・負荷・冗長化は未検証です。本成果物は基礎的なIaCと運用確認の演習であり、本番用高可用性サービスとしては評価していません。
