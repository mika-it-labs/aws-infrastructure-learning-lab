# 障害の切り分け（復習用）

次の表は想定時の確認観点です。この学習で各障害が発生したという記録ではありません。

|症状|確認する内容|
|---|---|
|Pipelineが開始しない|S3の対象キー・バージョン、イベント検知またはポーリング、ルールの対象と権限|
|Sourceが失敗|S3読み取り、バケットポリシー、バージョニング、KMSの権限|
|buildspecが見つからない|ZIPのルート階層、Buildspec設定のパス、意図したリビジョン|
|Pythonテスト失敗|最初の例外、実行ディレクトリ、Python版、依存関係、期待値。失敗を握りつぶさない|
|SSM接続不可|SSM Agent、インスタンスロール、通信経路、利用者の接続権限|
|CodeDeploy対象なし|タグとデプロイグループの条件、リージョン、Agentの状態|
|AppSpec/フック失敗|appspec.ymlの配置、YAML、相対パス、LF、権限、タイムアウト、実行ユーザー|
|S3 AccessDenied|実行主体、対象オブジェクト、IAM・バケット・KMS・明示的Deny|
|削除失敗|依存関係、ロールの関連付け、S3旧版、進行中の処理。失敗後の残存を再確認|

エラー全文の公開を避け、発生箇所・原因・変更内容・再確認結果を匿名化して記録します。旧ECS記録のIAM障害は[別資料](../archive/ecs-terraform-original/docs/troubleshooting.md)に保管しています。
