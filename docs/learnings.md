# 学びと次の確認

- CIではソースの取得、テスト、アーティファクトの受け渡しを分けて確認する。
- Pythonテスト成功は、EC2への配置やWebサービス稼働の成功を意味しない。
- SSM AgentとCodeDeploy Agent、EC2ロールと各サービスロールを区別する。
- ZIPの親ディレクトリ混入、AppSpecの位置、フックの相対パスを確認する。
- IAMは作成・実行だけでなく参照・関連付け解除・削除まで考える。
- 削除確認と請求確認を分け、残存リソースと旧バージョンを確認する。

上記は今回の整理による復習要点です。実施済み範囲と未確認事項は[学習記録](learning-record.md)、今後のIaC演習は[計画](ecs-terraform-plan.md)に記載しています。
