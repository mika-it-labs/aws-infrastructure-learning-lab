# 検証範囲と記録の限界

|対象|今回の確認|
|---|---|
|既存リポジトリ|GitHub連携でmainのツリー、README、docs、Terraformを調査|
|参照会話|取得可能な全5ターンを確認。過去の詳細実行ログ・元サンプルは取得できず|
|実施済み分類|今回の本人申告を根拠に整理。AWSの現状を独立検証していない|
|新規サンプル|ローカルでの検証結果は公開時チェックに記載。AWS実行結果とは分離|
|既存Terraform|原状保持。新たなinit・validate・plan・apply・destroyなし|
|旧記録|原文保存。そこに記載された実績や検査を今回の検証結果として再利用しない|

[公開時チェック](publication-checks.md)と[詳細記録](learning-record.md)を参照してください。
