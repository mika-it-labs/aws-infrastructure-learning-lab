# ECS/Fargate・Terraform 学習計画（未実施）

今回整理した学習範囲では計画段階です。既存terraform/と旧実施記録は保持していますが、この計画の完了根拠にはしません。

|時間|学習内容|完了時に残す証跡|
|---|---|---|
|20分|ECS、ECR、Fargate、EC2起動タイプの違い|責務・選択理由の説明|
|25分|クラスター、タスク定義、IAMをTerraformで定義|fmt、validate、planの結果と差分|
|25分|タスク起動・状態確認|起動結果、RUNNING/STOPPEDと理由|
|20分|CloudWatch Logs、CPU・メモリ、障害調査|ログ、メトリクス、原因の記録|
|20分|基本設計・詳細設計の演習|構成、ネットワーク、IAM、監視、運用の設計理由|
|10分|停止、削除、料金確認|停止完了、destroy、残存と課金の確認|

合計120分は目安です。Terraformはリソース定義・差分管理を担い、実行中タスク・ログ・料金は別途確認します。手動で起動したタスクをTerraform管理と誤認しないようにします。

既存コードはdefault VPC参照、東京リージョンとtrainingプロファイル、単発Fargate向けタスク定義、実行ロール、Logs、SGを含みます。ECSサービス・ALBの定義はありません。SGの受信許可はなく、HTTP公開演習には追加設計が必要です。実行前に共有環境への影響とplanを確認します。今回init・validate・plan・apply・destroyは実行していません。
